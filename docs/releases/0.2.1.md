# Vendroid 0.2.1

Vendroid 0.2.1 fixes the in-app language picker. It now lists all 40 languages that already ship with translations, shows each one by its native name, and scrolls when the list is taller than the screen.

Automatic is now truly automatic: the app follows the phone language when a translation exists and falls back to English only for unsupported languages. A phone set to Portuguese now opens Vendroid in Portuguese instead of English, and the same applies to French, Spanish, German, Chinese, and every other bundled language. An explicit choice keeps overriding the phone language as before.

Installing Ventoy erases the selected drive, so back it up first. Keep the drive connected until the operation finishes.

Testing covers building the app, unit tests for language resolution and persistence, Android lint, and the existing Appium language flow on a virtual device. One physical device and one USB drive do not establish compatibility with every device, drive, or firmware.
